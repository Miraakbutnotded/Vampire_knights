# Vampire Knights — canonical palette

Derived by median-cut from Alp's shipped character sprites (`public/assets/player/*.png`),
so new art matches what is already on screen rather than a palette invented on paper.
The last four are deliberate additions: Alp's set has no warm accent, no gold and no green,
and the hunter faction, coins and ground need them.
